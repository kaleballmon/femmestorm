# Femme Storm
Shereen's Site

## Installation
The full site is in the `femme-storm` subdirectory. When developing, first change directories to the `femme-storm` directory.

```shell
cd femme-storm/
```

To install the depedencies, run:

```shell
yarn install -D
```

> [!NOTE]
> `node >=22.12.0` is required. 

## Development
To run the development server, run:

```shell
yarn dev
```
